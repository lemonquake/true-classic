## 🌟 Overview

The **True Classic Bot** is a custom, fully integrated Discord Operations & Community Management bot designed exclusively for True Classic. Built with Python and `discord.py`, it replaces traditional 3rd-party bots (such as MEE6 or Dyno) with original, tailored features designed for creator management, automated onboarding, custom growth analytics, and persistent moderation control.

---

## 🚀 Key Modules & Original Features

1. **Persistent Moderation Control Panel (`/summon`)**
   - Live system health metrics, latency, database status, and pending broadcasts.
   - Remains persistent across bot reboots and gateway reconnects.

2. **Inner Group Triage & Summarizer (`/summarizer`)**
   - Automatically scans Inner Circle & Academy creator channels for pending/unanswered queries.
   - Generates deterministic triage reports and **Creator Care Briefs**.

3. **Custom Onboarding System (`/onboarding`)**
   - Deep-link DMs, group selection modals, and automated member scanning (0–30 days).

4. **Live Growth & Analytics Reports (`/memberreport`)**
   - Self-updating daily/weekly/monthly growth snapshots and join reconciliation.

5. **Scheduled Broadcast Engine (`/scheduled_messages`)**
   - Multi-channel targeting, timezone handling, 5-minute interval scheduling, and status tracking.

6. **Embed Script Engine & Interactive Editor (`/embededitor`)**
   - Dynamic variable hydrators, multi-embed pagination, and brand design system consistency.
